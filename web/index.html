    An executor with loadstring and game:HttpGet is required. It pulls every module from the repository, so updates are live the moment they are pushed.

    First run

    1. Create a profile. Profile Settings → type a name → Create New Profile. Nothing else works until a profile is loaded.
    2. Add targets. Farming → Targeting → Add Mob Target, and pick every mob you want it to fight.
    3. Leave Auto Farm on. Status → FARM STATE should change from IDLE (NO TARGET) to CHASE.
    4. Tune three settings. Safe Combat on, Retreat At HP% 40, Auto Find only if you do not want a route.
